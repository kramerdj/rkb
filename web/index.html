Incorporar a la colección

Mueve los temas preparados a la colección y los agrega a Rekordbox.

Temas preparados

  1. Backup de la base de Rekordbox.
  2. Mueve los archivos a la carpeta de la colección (sin pisar nada).
  3. Los agrega a Rekordbox con su metadata y sus My Tags automáticos.
  4. Después, en Rekordbox: seleccionalos → clic derecho → Analizar pista.

Conexión a internet y privacidad

          
Tu colección, tus archivos y tu base de Rekordbox nunca salen de tu computadora. La app se conecta a internet sólo para: buscar metadata y carátulas (en Descargas), leer playlists de Spotify, YouTube o Deezer, avisar si hay una versión nueva, mostrar la Cartelera (al servidor sólo se le dice el país que elegiste) y, si no las apagás en Ajustes, enviar estadísticas anónimas de uso a Aptabase (que se abrió la app, versión, sistema y qué funciones se usan; nunca temas, carpetas, nombres ni cantidades). Si publicás anuncios, se guarda tu email (no se muestra), tu nombre de DJ y lo que publicás.

Backup y restauración

Carpeta de backups
          

          Conviene que sea un disco externo: si se rompe la computadora, el backup queda a salvo.

      

      

      

        

          
Hacer un backup

          

            
            
            
            
          

          
La base se guarda en un zip con fecha (cada backup es uno nuevo). La colección se guarda como copia espejo: la primera vez copia todo y después sólo lo nuevo o cambiado. Lo que ya no está en tu colección no se borra del backup: se aparta en «_quitados».

          
Para la base, Rekordbox tiene que estar cerrado.

          

          

        

        

          
Restaurar

          
Base de Rekordbox

          
Vuelve la base al momento del backup. Antes de restaurar la app guarda la base actual, así podés volver atrás.

Privacidad

          
          
Sólo cuántas veces se instala y se abre la app, qué versión y sistema, y qué funciones se usan (como mucho una vez por día cada una). Nunca se envía nada de tu música ni de vos: ni temas, ni carpetas, ni nombres.

          
Claves de servicios (opcional)

          
          
          
          
          

          
          
Sin estas claves igual se pueden traer listas, hasta unos 100 temas. Las claves son gratis: Spotify en developer.spotify.com (crear una app) y YouTube en console.cloud.google.com (YouTube Data API v3).
